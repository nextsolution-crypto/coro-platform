# Display Manager

## Constats

Le workspace expose les appareils limités aux bâtiments autorisés, avec statut administratif, dernières communications/synchronisations et versions déclarées. Il n’invente pas ONLINE et conserve un mode de compatibilité si l’autorité Prisma est absente.

## Tests et limites

Les tests historiques de permissions passent après correction de compatibilité. Aucune recette UI authentifiée complète n’a été réalisée dans cette revue. Les modes/erreurs de la dernière télémétrie ne sont pas projetés dans la réponse, et l’administration des appareils manque.
