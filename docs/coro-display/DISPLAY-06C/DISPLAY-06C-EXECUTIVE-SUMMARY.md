# DISPLAY-06C — Synthèse

DISPLAY-06C relie les fondations 06A/06B à PostgreSQL et à un Gateway HTTP machine-to-machine. L’enrôlement, les nonces, les affectations, les séquences, les synchronisations et les événements sont persistés. Le runtime local sert le rendu sur loopback avec CSP et lance Chromium en kiosque sans `--no-sandbox`.

La chaîne est locale et synthétique. Aucun appareil, plan réel ou environnement de production n’est utilisé.
