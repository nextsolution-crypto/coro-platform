# Intégration CORO Ops

L’adaptateur minimal accepte la source `CORO_OPS` uniquement avec un `protocolId` explicite, une autorité Display valide et le reste des contrôles. Il ne convertit jamais seul une procédure documentaire en commande.

Limite : aucune tâche Ops dédiée n’est créée automatiquement dans cette itération; les escalades Display et le journal Incident fournissent la reprise minimale. L’orchestration Ops complète demeure NOT_VERIFIED.
