# Interface opérationnelle

Le Display Manager affiche une section « Commandes d’urgence Display » : bâtiment, action, incident, justification, confirmation explicite pour l’urgence réelle et historique des états. Les permissions désactivent les actions non autorisées.

Les tables sont navigables au clavier et scrollables sur mobile; focus visible et cibles de 44 px sont conservés. La sortie finale exige encore l’approbateur distinct via API; l’écran d’approbation dédié est une réserve UX.
