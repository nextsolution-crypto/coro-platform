# Ciblage des appareils

Le serveur résout zones ACTIVE → emplacements ACTIVE → appareils ACTIVE non révoqués, dans l’organisation et le bâtiment autorisés. Une liste explicite doit être un sous-ensemble exact. Chaque appareil ciblé doit avoir une affectation ACTIVE vers une publication PUBLISHED non révoquée et dotée d’une empreinte.

Le tableau de cibles est trié et gelé dans la commande signée. Une zone ou un appareil étranger provoque un refus avant écriture.
