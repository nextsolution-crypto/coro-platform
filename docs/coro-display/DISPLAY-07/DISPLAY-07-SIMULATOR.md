# Simulateur

Le simulateur logiciel utilise les contrats réels de signature, priorité, état local et accusés avec identités et plans synthétiques. Il ne contacte aucun appareil, Building Bridge, alarme, SMS ou courriel.

Le script Chromium rend cinq états (normal, exercice, urgence, hors ligne, restauré) sur trois profils et valide dimensions/contenu avant capture.
