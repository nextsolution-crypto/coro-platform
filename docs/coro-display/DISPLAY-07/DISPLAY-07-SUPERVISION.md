# Supervision

Le Display Manager expose les commandes par bâtiment, leur séquence, priorité, statut serveur et décompte par état de livraison. Les escalades ouvertes sont retournées séparément.

Le libellé UI précise que la déclaration Player n’est pas une observation physique. Un succès global n’est établi que si toutes les livraisons sont APPLIED; les états partiels restent visibles.
