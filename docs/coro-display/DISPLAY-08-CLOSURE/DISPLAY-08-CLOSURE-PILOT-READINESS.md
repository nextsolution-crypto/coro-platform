# Préparation du pilote

Référence proposée : Lenovo ThinkCentre M70q Gen 5, Ubuntu 24.04 LTS x86-64. Avant achat, confirmer SKU, CPU, RAM, SSD, TPM, sorties vidéo, réseau, compatibilité Ubuntu, fournisseur Ed25519, prix, disponibilité canadienne et garantie.

Le dossier DISPLAY-08 fournit les procédures d'installation, enrôlement, récupération et retrait. Le banc devra ajouter écran, support, alimentation, UPS et réseau d'essai, puis exécuter les recettes systemd, kiosque, urgence, hors ligne, coupure et endurance.

Aucun matériel n'a été acheté, installé ou enrôlé.
