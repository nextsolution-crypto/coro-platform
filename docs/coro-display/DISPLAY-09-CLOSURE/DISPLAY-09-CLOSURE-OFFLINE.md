# Hors ligne

Un rendu déjà chargé peut demeurer visible pendant la session. La fermeture, l’éviction du cache, le redémarrage du système ou certaines mises à jour peuvent toutefois supprimer cette capacité.

Aucune garantie permanente hors ligne n’est revendiquée. Une fonction de sécurité critique ne doit pas dépendre de ce cache navigateur.
