# Risques résiduels

- Jeton navigateur copiable; absence d’identité matérielle.
- Cache persistant après éviction ou redémarrage non garanti.
- Validation iPad/MDM/kiosque physique : `NOT_VERIFIED`.
- `WEB_MANAGED_KIOSK` : non autorisé.
- `WEB_EMERGENCY_ELIGIBLE` : non autorisé.
- Observation physique indépendante de l’affichage : non réalisée.
