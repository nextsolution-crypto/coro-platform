# Préparation du pilote iPad

Le pilote suivant utilisera un bâtiment et un emplacement synthétiques, un PDF fictif V1/V2 et une session `WEB_VIEW_ONLY` sur l’iPad de référence MD3Y4CL/A.

À exécuter séparément : création d’emplacement, import documentaire, approbation, publication, activation Safari, rendu, V2, reconnexion, perte réseau et révocation. Aucun essai physique n’a été réalisé dans DISPLAY-09.
