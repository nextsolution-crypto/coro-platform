# Gouvernance documentaire

DISPLAY-09 réutilise la publication documentaire existante : seul un document privé approuvé et sa version publiée peuvent être résolus par le Player.

Le parcours d’import complet demeure celui du gestionnaire documentaire existant. DISPLAY-09 expose la sélection de publication; il ne revendique pas un nouveau moteur d’import ou d’approbation.
