# Endurance

## Mesures réellement exécutées

Les tests unitaires durent moins de quelques secondes; l'E2E intégré environ une minute avec migrations/Chromium. Aucune campagne 8 h ou 24 h n'a été exécutée.

## Verdict

CPU, RAM, croissance du journal/cache, reconnexions longues et fuite Chromium: **NOT_VERIFIED**. Les rapports initiaux ne contiennent pas une mesure suffisante pour revendiquer une endurance prolongée. Condition pilote: campagne instrumentée ≥8 h, puis 24 h, avec seuils préapprouvés.
