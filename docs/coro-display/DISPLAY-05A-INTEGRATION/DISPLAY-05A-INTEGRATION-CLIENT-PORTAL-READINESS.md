# DISPLAY-05A-INTEGRATION — Préparation DISPLAY-05B

## Contrats réutilisables

Le portail pourra réutiliser la portée organisation/bâtiment, `DISPLAY_READ`, `DISPLAY_PLAN_READ`, l'arbre spatial, la liste filtrée/paginée, l'historique autorisé et le téléchargement privé par blob.

## Séparation obligatoire

Le futur acteur client pourra consulter les bâtiments, plans, emplacements et versions autorisés, puis proposer une correction dans une autorité séparée et auditée. Il ne pourra ni modifier un plan approuvé, ni approuver, publier, révoquer, réaffecter, diffuser ou déclencher une urgence.

## Travaux futurs identifiés

Définir une permission de proposition, un modèle d'observation immuable, la modération, les notifications, les quotas et la rétention. Aucun de ces éléments n'est implémenté par DISPLAY-05A-INTEGRATION.

## État

Compatibilité technique préservée; DISPLAY-05B n'a pas commencé.
