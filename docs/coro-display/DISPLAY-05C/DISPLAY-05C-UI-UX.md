# UI / UX

La section est intégrée au Manager `/display` et respecte AppLayout. Elle comprend compteurs serveur, recherche, filtres, liste, panneau détaillé, qualification, attribution, communication, transitions et historique conditionné par permission.

Une observation critique porte un libellé textuel, un contraste dédié et une consigne d'urgence prudente; la couleur n'est pas le seul signal. Le CSS inclut les paliers 1100/760 px, les focus visibles et `prefers-reduced-motion`.
