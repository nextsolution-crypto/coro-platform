# Visibilité client

Le portail conserve le modèle DISPLAY-05B limité à l'auteur. Il retourne le statut, la réponse communicable, les dates de décision/résolution/clôture et uniquement les messages dont la visibilité est `CLIENT`.

Les commentaires `INTERNAL`, utilisateurs professionnels, événements techniques et notes de sécurité ne sont jamais sélectionnés par le service client.
