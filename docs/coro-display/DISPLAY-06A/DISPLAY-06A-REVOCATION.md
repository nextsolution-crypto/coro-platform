# DISPLAY-06A — Révocation

Une révocation connue bloque le plan. Une révocation reçue pendant la synchronisation devient immédiatement connue localement. Hors ligne, l'absence de nouvelle information est signalée comme actualité non confirmée et non comme absence de révocation.

Le Player ne revient jamais vers un plan plus ancien révoqué. Si le remplacement est absent ou invalide et qu'aucun plan admissible ne reste, il entre en mode dégradé explicite. La présentation finale de ce mode doit être validée humainement avant exploitation.
