# Responsive et accessibilité

Le build Next production passe. Les contrôles possèdent des libellés et focus visibles, les messages utilisent `role=alert/status`, le bouton plein écran est explicite et le mouvement est neutralisé avec `prefers-reduced-motion`.

La grille passe de 3 à 2 puis 1 colonne. Les tableaux restent défilables. Les coordonnées sont désormais celles de l’image, y compris avec zoom.

Inspection navigateur réelle bureau/tablette/mobile : **NOT_VERIFIED**. L’annotation clavier directe reste une limite V1; le formulaire sans annotation reste entièrement clavier.
