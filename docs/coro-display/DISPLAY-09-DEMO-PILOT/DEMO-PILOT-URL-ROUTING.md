# URL et routage

Format maintenu : `https://display.getcoro.io/d/{publicDisplayId}`. L'identifiant est généré par DISPLAY-09, opaque, associé à l'emplacement et distinct de l'identité navigateur. Aucun identifiant d'exemple n'est réservé par cette branche.

La rotation/révocation et les codes d'activation restent servis par les contrats Display Web existants; le lien bâtiment ajouté ne contourne pas ces contrats. DNS, TLS, reverse proxy et origine `display.getcoro.io` sont **NOT_VERIFIED** et n'ont pas été modifiés.
