# Synchronisation

Les contrats existants séparent manifeste, téléchargement privé, confirmation logicielle et supervision. Le scénario prévu est V1 publiée/confirmée, puis V2 publiée/détectée/confirmée sans mutation de V1.

Cette branche ne modifie pas le moteur de synchronisation. Les régressions unitaires Display passent; aucune confirmation physique iPad n'a été exécutée. Une confirmation navigateur ne doit jamais être décrite comme une preuve d'affichage physique.
