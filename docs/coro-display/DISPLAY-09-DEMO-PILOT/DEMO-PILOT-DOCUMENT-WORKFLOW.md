# Flux documentaire

Le pilote réutilise CORO Documents et DISPLAY-04 : fichier privé → validation PDF → rendu → approbation → nouvelle publication → affectation. Aucun second moteur PDF et aucune publication automatique n'ont été ajoutés.

V1 et V2 sont des fichiers distincts. L'ancienne version doit rester immuable et traçable. L'import HTTP, l'approbation et la publication de ces actifs précis sur PostgreSQL jetable restent **NOT_VERIFIED**; seule leur validité documentaire locale est démontrée ici.
