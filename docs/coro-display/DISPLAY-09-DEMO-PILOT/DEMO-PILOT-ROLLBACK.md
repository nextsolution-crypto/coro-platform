# Rollback

Le code portail est réversible par retour au SHA antérieur. La fixture est réversible uniquement en supprimant les ressources portant la clé externe déterministe, après contrôle qu'aucune référence non-démo n'existe.

Ne jamais supprimer les PDF/documents Tour Prémont existants. Révoquer invitations/sessions de démonstration avant retrait de l'emplacement. Un rollback backend doit conserver les garanties DISPLAY-09; la simple présence d'une image n'établit pas sa sécurité.
