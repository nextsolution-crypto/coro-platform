# Responsive et accessibilité

La structure existante est préservée. Les champs ajoutés utilisent des `label`, `fieldset` et `legend`; les boutons restent natifs et les transitions interdites sont absentes plutôt que seulement décorées. Les catégories présentées correspondent maintenant à l’enum Prisma canonique.

Les builds et contrats frontend passent. La vérification visuelle et clavier réelle aux largeurs demandées reste `NOT_VERIFIED` pour la raison documentée dans le rapport navigateur.
