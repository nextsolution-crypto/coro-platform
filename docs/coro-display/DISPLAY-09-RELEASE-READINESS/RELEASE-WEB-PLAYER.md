# Player Web

Route candidate : `/d/{publicDisplayId}`. Activation P-256 WebCrypto, session opaque, manifest signé, publication approuvée, confirmation/synchronisation et révocation sont couvertes par les services et tests Display.

Le pilote est strictement `WEB_VIEW_ONLY`; `WEB_MANAGED_KIOSK` et `WEB_EMERGENCY_ELIGIBLE` restent interdits. Le Player ne constitue pas un remplacement réglementaire automatique d'un plan mural. L'URL publique réelle et l'iPad ne sont pas activés.
