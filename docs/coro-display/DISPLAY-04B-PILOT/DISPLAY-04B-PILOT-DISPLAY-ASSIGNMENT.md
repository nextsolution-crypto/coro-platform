# DISPLAY-04B-PILOT — Display assignment

The DISPLAY-03 service remains the authority for DRAFT, REVIEW, APPROVED, PUBLISHED, SUSPENDED, SUPERSEDED, and REVOKED transitions. The pilot did not add a second assignment authority.

The disposable PostgreSQL test exercised assignment of the exact approved source/render to a governed synthetic display location, denial for an unrelated building/location, and immediate revocation. The PUBLISHED transition existed only in the isolated database; no Player, screen, or production endpoint received the document.

Suggested demonstration mappings after human approval are the three target profiles documented in the rendering report. They are prepared artifacts, not active assignments.
