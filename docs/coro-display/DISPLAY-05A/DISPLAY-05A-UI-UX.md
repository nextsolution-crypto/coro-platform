# UI / UX

L'écran contient une synthèse, un arbre bâtiment/étage/zone, une bibliothèque filtrable, des cartes homogènes, un panneau de détail, un aperçu privé plein écran, les sources admissibles et l'activité récente.

Les points de rupture couvrent grand écran, tablette et mobile; la grille passe de trois à deux puis une colonne. Les focus sont visibles, le dialogue est nommé, les erreurs utilisent `role=alert` et `prefers-reduced-motion` est respecté.

Réserve : la recette visuelle authentifiée réelle et les captures sont `NOT_VERIFIED`; aucun jeu de données fictif n'a été injecté pour produire de fausses captures.
