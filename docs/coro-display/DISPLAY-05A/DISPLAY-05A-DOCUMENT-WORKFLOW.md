# Flux documentaire

1. Importer le PDF dans CORO Documents.
2. Faire progresser le fichier dans son cycle documentaire existant.
3. Le gestionnaire ne propose que le PDF d'évacuation approuvé, courant et lié au bâtiment autorisé.
4. Créer une publication avec version et SHA source exacts.
5. Générer une variante privée, revoir, approuver avec le profil visuel exact, puis publier si l'autorité l'autorise.
6. Les changements de source rendent les contrôles d'autorité existants applicables; aucune validation n'est copiée.

L'interface ne téléverse pas directement de fichier et ne remplace donc pas CORO Documents.
