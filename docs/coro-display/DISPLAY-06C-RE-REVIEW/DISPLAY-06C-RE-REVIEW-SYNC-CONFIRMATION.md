# Confirmation de synchronisation

La confirmation M2M lie appareil, sync, affectation, publication, version, séquence, empreinte et instant d’activation. La base contient une sync `CONFIRMED`; une confirmation tardive ne peut pas abaisser la séquence acceptée.

Cette confirmation prouve l’activation logicielle, pas la visibilité physique. Résultat logiciel : PASS.
