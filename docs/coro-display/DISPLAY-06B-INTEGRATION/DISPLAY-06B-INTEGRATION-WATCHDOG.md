# DISPLAY-06B-INTEGRATION — Watchdog

Le budget local borne les redémarrages dans une fenêtre glissante et les tests couvrent la boucle de crash. Il ne supprime ni cache ni urgence.

Heartbeat, détection de blocage, backoff persistant, journalisation et superviseur Windows/Linux sont **NOT_IMPLEMENTED**. Aucun watchdog OS opérationnel n'est revendiqué.
