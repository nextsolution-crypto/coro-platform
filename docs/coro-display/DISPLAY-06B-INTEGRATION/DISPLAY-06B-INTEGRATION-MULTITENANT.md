# DISPLAY-06B-INTEGRATION — Multitenant

Trois organisations synthétiques avec bâtiments, emplacements, appareils et affectations distincts sont validées. La substitution d'un manifeste B vers l'appareil A est refusée par la portée signée.

Cette preuve est logique. Les politiques RLS/transactions PostgreSQL et contrôleurs HTTP d'appareil ne sont pas encore implémentés; aucune garantie frontend seule n'est revendiquée.
