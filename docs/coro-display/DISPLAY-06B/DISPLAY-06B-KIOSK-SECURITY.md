# DISPLAY-06B — Sécurité kiosque

La politique exige `--kiosk`, refuse `--no-sandbox`, `--disable-web-security`, certificats ignorés et extensions chargées. Aucun privilège administrateur ou port public n'est prévu.

Le lancement réel, l'origine locale, l'isolation OS et le démarrage automatique sont **NOT_IMPLEMENTED**; seuls les contrôles de configuration sont livrés.
