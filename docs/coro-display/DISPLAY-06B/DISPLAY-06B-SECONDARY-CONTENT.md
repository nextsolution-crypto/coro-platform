# DISPLAY-06B — Contenus secondaires

Le booléen `authenticated` seul n'est plus une preuve suffisante. Le contenu est lié à organisation, bâtiment, version, dates, approbation, révocation, empreinte et clé; signature Ed25519 et média sont vérifiés avant admissibilité.

Aucun HTML ou script distant n'est accepté.
