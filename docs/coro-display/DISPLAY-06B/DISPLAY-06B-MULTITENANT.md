# DISPLAY-06B — Multitenant

Invitations, appareil, requêtes, manifeste et contenus sont liés à des identifiants opaques de portée. Les preuves étrangères et les bâtiments divergents sont refusés. Aucun téléchargement n'est décidé par un identifiant client seul.

Les politiques PostgreSQL et contrôleurs Gateway doivent encore appliquer ces mêmes invariants.
