# DISPLAY-06B — Synchronisation

Le protocole valide identité, manifeste, portée, affectation et séquence; exige `private://`; refuse un téléchargement incomplet; revérifie SHA-256; puis commet atomiquement. Une erreur conserve la génération courante.

L'adaptateur réseau authentifié et la reprise par plages sont des interfaces futures; aucune URL publique permanente n'est créée.
