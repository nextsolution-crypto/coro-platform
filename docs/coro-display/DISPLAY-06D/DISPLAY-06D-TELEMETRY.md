# Télémétrie

Heartbeat : version, mode, séquence, santé cache/runtime, réseau et erreurs. Le serveur retourne `physicalDisplayProof=false`; la télémétrie est une déclaration authentifiée, pas une preuve visuelle.

Le scénario E2E a persisté un heartbeat à `2026-11-12T02:53:35.566Z` et une synchronisation `CONFIRMED`. Les redémarrages et incidents locaux sont réconciliés séparément.
