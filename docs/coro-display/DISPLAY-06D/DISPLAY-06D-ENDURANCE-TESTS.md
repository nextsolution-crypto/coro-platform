# Essais d’endurance

Les suites répétées ont vérifié journal, cache, redémarrage et Chromium, mais aucune exécution continue de plusieurs heures n’a été achevée dans cette passe. Aucune métrique CPU/mémoire longue durée n’est inventée.

Verdict : **NOT_VERIFIED** pour l’endurance exigée. Le pilote devra exécuter au moins 8 h synthétiques puis 24 h sur matériel, relever RSS/CPU/disque toutes les minutes, imposer reconnexions et crashes, et refuser toute boucle de restart.
