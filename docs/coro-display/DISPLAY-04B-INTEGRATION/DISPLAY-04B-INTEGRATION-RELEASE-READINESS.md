# Préparation de release

La branche est candidate à une PR locale : intégration sans conflit, build reproductible, migrations idempotentes, contrats de sécurité et de gouvernance validés, aucune donnée privée ou dépendance nouvelle.

Avant diffusion opérationnelle, il faut encore :

1. faire réviser la PR;
2. obtenir une approbation documentaire et visuelle humaine explicite;
3. effectuer la recette physique sur l'écran et l'emplacement exacts;
4. conserver les empreintes exactes lors de cette approbation.

Aucun push, PR, merge, déploiement, migration partagée ou diffusion physique n'a été effectué.
