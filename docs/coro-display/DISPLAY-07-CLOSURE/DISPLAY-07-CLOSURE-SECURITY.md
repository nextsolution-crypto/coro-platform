# Sécurité

Les commandes portent organisation, bâtiment, zone, appareil, incident, source, priorité, séquence, horodatage et version de contrat. La signature Ed25519, l'anti-rejeu, l'anti-rollback, la révocation et l'autorité spatiale sont appliqués avant changement d'état.

La route humaine interdit les provenances machine privilégiées. Le simulateur exige un exercice. Les publications doivent être approuvées et applicables; aucun brouillon, plan étranger ou itinéraire IA n'est admissible.

Audit runtime : zéro vulnérabilité. Trois vulnérabilités élevées demeurent dans l'outillage de développement et ne sont pas chargées dans les images runtime. Aucun secret n'a été ajouté.
