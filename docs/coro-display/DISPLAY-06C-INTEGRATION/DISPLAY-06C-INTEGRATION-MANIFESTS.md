# Manifestes

Le payload canonique est signé Ed25519 et vérifié avec schéma strict, clé de confiance, temps, portée, profil, dimensions, affectation, séquence, révocation et SHA-256. Les clés du test sont synthétiques.

Preuve E2E : séquence `1`, SHA-256 `36ee1edf742e4418d6bf9b51c7b79cef098678a44fdaa6f62e16cafb0f0f08b0` conservé du rendu autorisé au processus redémarré.
