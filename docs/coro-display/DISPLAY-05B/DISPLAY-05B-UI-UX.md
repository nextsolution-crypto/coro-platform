# DISPLAY-05B — UI/UX

Route : `/display`, visible seulement avec `DISPLAY_CLIENT_PLAN_READ`.

L’interface suit le portail existant : cartes de synthèse, filtre bâtiment, recherche, cartes documentaires, badge « Consultable » ou « Diffusé sur écran », aperçu zoomable et formulaire accessible. Le clic sur l’aperçu positionne l’annotation. Les tableaux deviennent défilables et les grilles passent de trois à deux puis une colonne. Les focus sont visibles et les animations sont supprimées avec `prefers-reduced-motion`.
