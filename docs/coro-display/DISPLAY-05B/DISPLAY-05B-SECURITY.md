# DISPLAY-05B — Sécurité

Contrôles : authentification client, compte et client actifs, permissions dédiées rechargées, organisation/client/bâtiment croisés, publication et emplacement exacts, statut autorisé, stockage privé, intégrité SHA-256, réponse `nosniff` et absence de cache.

Les observations sont privées à leur auteur, même dans la même organisation. Les commentaires internes ne sont pas exposés. Les pièces jointes sont désactivées : aucun stockage public ni fichier arbitraire n’est accepté.

Les routes Manager existantes conservent leur authentification conseiller; aucune capacité Manager n’est importée dans le portail.
