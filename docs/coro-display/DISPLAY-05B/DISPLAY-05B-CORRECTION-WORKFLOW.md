# DISPLAY-05B — Workflow de correction

États : `SUBMITTED`, `UNDER_REVIEW`, `MORE_INFO_REQUIRED`, `ACCEPTED`, `REJECTED`, `CORRECTION_IN_PROGRESS`, `RESOLVED`, `CLOSED`.

DISPLAY-05B crée seulement `SUBMITTED`. Les transitions humaines seront traitées par DISPLAY-05C; aucun automatisme n’est amorcé ici. Une priorité `CRITICAL` affiche une consigne de contacter les responsables ou services d’urgence, sans incident, notification promise ni évacuation automatique.

Les coordonnées facultatives sont normalisées entre 0 et 1 et figées avec la version et le SHA-256 du rendu.
