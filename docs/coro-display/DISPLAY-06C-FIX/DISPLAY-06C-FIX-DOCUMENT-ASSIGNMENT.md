# Affectation documentaire

Une affectation référence directement `DisplayPlanPublication`. Le service d'administration exige organisation, bâtiment et emplacement identiques, statut `PUBLISHED`, stockage/empreinte présents, absence de révocation et absence de supersession.

Une nouvelle affectation révoque les anciennes affectations actives du même appareil dans la transaction. Aucun brouillon, plan refusé ou publication étrangère n'est distribuable.
