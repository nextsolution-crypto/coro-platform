# Manifestes

Le Gateway émet le contrat strict DISPLAY-06A/06B avec organisation, bâtiment, emplacement, affectation, publication, version, profil, dimensions, SHA-256, séquence et politique. La signature utilise `ManifestSigner`; le test emploie exclusivement une paire Ed25519 synthétique.

Le Player valide signature, clé de confiance, fenêtre temporelle, étendue, profil, séquence et octets. Les suites adversariales couvrent falsification, clé inconnue/révoquée et rollback.
