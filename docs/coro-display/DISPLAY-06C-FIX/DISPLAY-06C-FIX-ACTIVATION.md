# Activation

`ConnectedPlayerService.synchronize()` distingue manifeste reçu, rendu téléchargé, rendu vérifié, commit cache, relecture vérifiée, activation en mémoire et confirmation serveur. `activeBytes()` ne renvoie rien avant activation.

Le fichier présenté par l'origine loopback provient de cette activation; le chemin synthétique codé en dur a été retiré du Player principal.
