# Revue indépendante

Points de revue obligatoires : token navigateur copiable, persistance hors ligne limitée, absence de preuve physique, génération publique et révocation atomique. Conclusion provisoire : acceptable uniquement comme `WEB_VIEW_ONLY`; toute capacité d'urgence ou kiosque géré demeure hors périmètre sans preuves supplémentaires.
