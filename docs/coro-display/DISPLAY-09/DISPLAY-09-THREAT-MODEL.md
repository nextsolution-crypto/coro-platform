# Modèle de menaces

Contrôles : identifiant opaque, réponse générique aux identifiants inconnus, code haché/expirant/usage unique, essais bornés, token 256 bits, révocation serveur, CSP, anti-frame, no-referrer, stockage privé et empreinte. Limite : le token local du profil `WEB_VIEW_ONLY` n'est pas une identité matérielle; ne pas promouvoir ce profil à l'urgence.
