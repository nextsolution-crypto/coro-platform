# Risques résiduels

- Token `WEB_VIEW_ONLY` stocké localement et non assimilable à une identité matérielle.
- Cache persistant hors ligne non garanti sur tous les navigateurs.
- Kiosque/MDM et appareils réels non testés.
- DNS `display.getcoro.io` non configuré.
- Observation physique distincte de la confirmation déclarée.
- Dépendances de développement : dette d'audit historique à qualifier, sans mise à jour forcée.
