# DISPLAY-09 — Résumé

DISPLAY-09 ajoute une URL permanente opaque par emplacement, une activation Web temporaire à usage unique, une session de navigateur révocable et un Player Web limité à `WEB_VIEW_ONLY`. Les publications approuvées, le stockage privé et les permissions Display existants sont réutilisés. Aucun DNS, appareil ou environnement partagé n'est modifié.
