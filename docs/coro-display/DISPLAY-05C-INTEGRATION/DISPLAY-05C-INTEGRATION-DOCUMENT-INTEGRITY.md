# Intégrité documentaire

Une observation référence la publication, le `ProjectFile`, sa version et son empreinte; elle ne les modifie jamais. Les décisions ne génèrent ni PDF, ni version, ni publication, ni approbation, ni commande d’écran.

Les tests PostgreSQL comparent les enregistrements documentaires avant/après le workflow et confirment leur immutabilité. Les références de correction sont conservées sans remplacer le document source et sans être présentées comme preuve automatiquement vérifiée.

Aucun PDF réel, rendu privé ou donnée client n’a été ajouté au diff.
