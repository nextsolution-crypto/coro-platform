# DISPLAY-06A-INTEGRATION — Hors ligne

Un plan dont l'authenticité et l'intégrité ont été vérifiées reste affichable hors ligne. Après sa date de réévaluation, il est explicitement marqué `FRESHNESS_UNCONFIRMED`; le Player ne prétend pas connaître une révocation distante survenue pendant la coupure.

Plan absent, corrompu ou révoqué connu : aucun affichage prétendument approuvé. Une synchronisation échouée conserve la dernière copie valide.
