# DISPLAY-06A-INTEGRATION — Clés de confiance

Seules les clés publiques déjà présentes dans le registre local sont admissibles. Le validateur contrôle activation, expiration et révocation par rapport à la date d'émission. Une clé fournie par le manifeste lui-même n'acquiert aucune confiance.

La distribution authentifiée, la rotation persistante et la récupération du registre restent des contrats DISPLAY-06B. Aucune clé privée ou production n'est incluse.
