# Independent physical observation

A heartbeat proves protocol activity, not visible pixels. Pilot evidence therefore requires a second observer to compare displayed plan/version/mode with Manager state and record timestamp, asset ID, screen profile and outcome.

Preferred initial method: human observation plus privacy-reviewed photograph showing only the screen and a run identifier. EDID confirms a connected sink but not visibility; a luminance meter can support, not replace, observation.

Continuous camera monitoring is excluded until a privacy/security assessment and explicit authorization. No physical observation has occurred.
