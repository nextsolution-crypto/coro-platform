# UPS

Sizing method: measure combined mini-PC + display watts at normal and peak, add 25% margin, select an IEC/CSA-compatible UPS, then measure runtime at that load. Required signals: on-battery, low-battery, controlled shutdown and restored power.

The UPS daemon may request shutdown but cannot clear emergency state or modify content. Batteries require asset ID, install date, periodic self-test and governed replacement.

No model, wattage, runtime, price or purchase is approved. All UPS capacity/autonomy claims are **NOT_VERIFIED** pending physical measurement and supplier data.
