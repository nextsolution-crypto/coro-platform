# Display profiles

Profiles validated in code: 17:11 landscape, 16:9 and 16:10. Resolution must be integral, at least 1280 px wide and within 0.035 aspect-ratio tolerance. CSS always contains the entire approved render; cropping is forbidden.

Existing Chromium evidence contains normal, exercise, emergency, offline and restored captures for the three profiles. It demonstrates pixels, not physical legibility.

Pilot measurement: record EDID/native resolution, orientation, diagonal, mounting height, viewing distance, ambient illuminance, luminance/contrast and observer result. No physical result is claimed.
